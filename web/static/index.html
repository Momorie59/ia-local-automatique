🧠CONNECTER MOMORY CLI

Télécharge momory-cli directement depuis ce serveur, sur n'importe quelle machine (Windows, Mac, Linux) — pas besoin d'aller le chercher ailleurs.

⬇ Télécharger momory-cli.zip
Sur la machine cliente — modifiable directement ici avant de copier :
🪟 Windows — PowerShell (invite bleue "PS C:\...")
Invoke-WebRequest http://—:7842/download/momory-cli.zip -OutFile momory-cli.zip; Expand-Archive momory-cli.zip -Force; cd momory-cli; npm install; npm run build; npm link
⬛ Windows — Invite de commandes (CMD) (invite noire "C:\...")
curl -o momory-cli.zip http://—:7842/download/momory-cli.zip && tar -xf momory-cli.zip && cd momory-cli && npm install && npm run build && npm link
🐧 Mac / Linux
curl -O http://—:7842/download/momory-cli.zip && unzip momory-cli.zip && cd momory-cli && npm install && npm run build && npm link

🤖CONNECTER UN ÉDITEUR (ANDROID STUDIO / INTELLIJ)

Ollama expose une API compatible OpenAI. N'importe quel plugin IA d'Android Studio / IntelliJ qui accepte une URL d'API personnalisée (ex: Continue, CodeGPT, Tabby) peut s'y connecter — ton code ne quitte jamais ta machine.

  1. Installe le plugin de ton choix depuis le Marketplace d'Android Studio (Settings → Plugins)
  2. Dans les réglages du plugin, choisis un provider OpenAI-compatible / Ollama
  3. Colle l'URL de l'API ci-dessous comme endpoint
  4. Choisis un modèle installé (visible dans l'onglet Administration → Modèles)
